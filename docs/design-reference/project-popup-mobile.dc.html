Overview

I designed and built a modular rotating structure that points highly directive antennas at satellites in low Earth orbit and follows them across the sky — from mechanics and firmware to orbit prediction and the web interface.

How it works

  1. 01 · Hardware

    Mechanics & parts

    3D-modelled the structure and selected motors and components.

  2. 02 · Firmware

    Motor control

    Turns pointing commands into precise motor movement.

  3. 03 · Orbits

    Satellite tracking

    C code reading TLE data and propagating orbits with SGP4.

  4. 04 · Interface

    Web control panel

    Choose satellites, start tracking and monitor the system.
