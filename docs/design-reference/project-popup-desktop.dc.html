Overview

I designed and built a modular rotating structure that points highly directive antennas at satellites in low Earth orbit and follows them across the sky. The work covered every layer of the system: the mechanical design and parts, the firmware that drives the motors, the C code that predicts each satellite's position, and the web interface researchers use to control it.

[Why it was needed — the problem it solved for the team]

How it works

  1. 01 · Hardware Mechanics & parts 3D-modelled the rotating structure and selected the motors, drivers and components.
  2. 02 · Firmware Motor control Firmware that turns pointing commands into precise motor movement.
  3. 03 · Orbits Satellite tracking C code that reads TLE data and propagates each orbit with SGP4 to know where to point.
  4. 04 · Interface Web control panel A browser interface to choose satellites, start tracking and monitor the system.
